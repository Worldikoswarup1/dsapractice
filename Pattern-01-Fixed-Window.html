1. LC 643 — Maximum Average Subarray I

Open on LeetCode

Problem

You get an integer array nums and an integer k. Look at every contiguous subarray of exactly k elements and return the largest average among them. Answers within 10⁻⁵ are accepted.

Example 1

Input:       nums = [1,12,-5,-6,50,3], k = 4
Output:      12.75
Explanation: Windows of size 4 have sums 2, 51, 42. Best sum 51, so 51 / 4 = 12.75.

Example 2

Input:       nums = [5], k = 1
Output:      5.0
Explanation: Only one window.

Constraints: 1 ≤ k ≤ n ≤ 10⁵, -10⁴ ≤ nums[i] ≤ 10⁴

Solution

class Solution {
public:
    double findMaxAverage(vector<int>& nums, int k) {
        int n = nums.size();                         // number of elements
        int left = 0, right = 0;                     // window is nums[left..right]
        int windowSum = 0;                           // sum of the current window
        int bestSum = INT_MIN;                       // biggest window sum seen so far

        while (right < n) {                          // grow the window one element at a time
            windowSum += nums[right];                // ADD: nums[right] enters the window

            while (right - left + 1 > k) {           // window became bigger than k
                windowSum -= nums[left];             // REMOVE: nums[left] leaves the window
                left++;                              // shrink from the left
            }

            if (right - left + 1 == k) {             // window has exactly k elements
                bestSum = max(bestSum, windowSum);   // UPDATE: keep the biggest sum
            }
            right++;                                 // move to the next element
        }
        return (double)bestSum / k;                  // max average = max sum / k
    }
};

Time & Space Complexity: Time O(n): right n baar aage badhta hai aur left bhi total n baar se zyada nahi, toh har element ek baar aata hai aur ek baar jaata hai. Space O(1): sirf kuch variables.

4. LC 2090 — K Radius Subarray Averages

Open on LeetCode

Problem

For each index i, take the k elements on its left, nums[i] itself and the k elements on its right (2k+1 elements). Their average, rounded down, is the k-radius average of i. If i does not have k elements on both sides, its answer is −1. Return the array of answers.

Example 1

Input:       nums = [7,4,3,9,1,8,5,2,6], k = 3
Output:      [-1,-1,-1,5,4,4,-1,-1,-1]
Explanation: avg[0], avg[1], avg[2] are -1: fewer than k elements on their left.
             avg[3] = (7+4+3+9+1+8+5) / 7 = 37 / 7 = 5 (rounded down).
             avg[4] = (4+3+9+1+8+5+2) / 7 = 32 / 7 = 4.
             avg[5] = (3+9+1+8+5+2+6) / 7 = 34 / 7 = 4.
             avg[6], avg[7], avg[8] are -1: fewer than k elements on their right.

Figure (Example 1, k-radius window of index 3)

index :  0   1   2   3   4   5   6   7   8
nums  :  7   4   3   9   1   8   5   2   6
        [- k = 3 -]     [- k = 3 -]
                     ^
                  center i = 3

window = nums[0..6] = [7,4,3,9,1,8,5]
sum = 37, average = 37 / 7 = 5  ->  avg[3] = 5

Example 2

Input:       nums = [100000], k = 0
Output:      [100000]
Explanation: k = 0 means the window is just the element itself.

Example 3

Input:       nums = [8], k = 100000
Output:      [-1]
Explanation: No room on either side.

Constraints: 1 ≤ n ≤ 10⁵, 0 ≤ nums[i], k ≤ 10⁵

Solution

class Solution {
public:
    vector<int> getAverages(vector<int>& nums, int k) {   // ✏️ changed
        int n = nums.size();                         // number of elements
        int left = 0, right = 0;                     // window is nums[left..right]
        long long windowSum = 0;                     // ✏️ changed | sum can reach (2 x 10^5 + 1) x 10^5, more than int
        int windowSize = 2 * k + 1;                  // ✏️ changed | k on the left + center + k on the right
        vector<int> averages(n, -1);                 // ✏️ changed | -1 where a full window does not fit

        while (right < n) {                          // grow the window one element at a time
            windowSum += nums[right];                // ADD: nums[right] enters the window

            while (right - left + 1 > windowSize) {  // ✏️ changed | window became bigger than windowSize
                windowSum -= nums[left];             // REMOVE: nums[left] leaves the window
                left++;                              // shrink from the left
            }

            if (right - left + 1 == windowSize) {    // ✏️ changed | window is full
                averages[left + k] = windowSum / windowSize;   // ✏️ changed | UPDATE: average goes to the center index
            }
            right++;                                 // move to the next element
        }
        return averages;                             // ✏️ changed | average for every index
    }
};

Time & Space Complexity: Time O(n): har element ek baar aata hai, ek baar jaata hai. Space O(1) extra (output array alag).

5. LC 2269 — Find the K-Beauty of a Number

Open on LeetCode

Problem

Read num as a string of digits. Look at every substring of length k (as a number; leading zeros are allowed). Count how many of them are non-zero and divide num exactly.

Example 1

Input:       num = 240, k = 2
Output:      2
Explanation: '24' divides 240 and '40' divides 240.

Example 2

Input:       num = 430043, k = 2
Output:      2
Explanation: '43' yes, '30' no, '00' is 0 (skip), '04' = 4 no, '43' yes.

Constraints: 1 ≤ num ≤ 10⁹, 1 ≤ k ≤ number of digits

Solution

class Solution {
public:
    int divisorSubstrings(int num, int k) {
        int l = 0, r = 0, cnt = 0;
    
        string digit = to_string(num);
        int n = digit.size();

        string ans = "";
        
        while(r < n){
            ans += digit[r];

            while(r - l + 1 > k){
                ans.erase(0, 1); 
                l++;
            }

            if((r - l + 1 == k) && (stoi(ans) != 0) && (num % stoi(ans) == 0))cnt++;
            r++; 
        }
        return cnt;
    }
};

Time & Space Complexity: Time O(d × k): har step pe ans.erase(0, 1) aur stoi(ans) O(k) lete hain, jahan d = digits (≤ 10). Space O(d), digit aur ans strings ke liye.

6. LC 1456 — Maximum Number of Vowels in a Substring of Given Length

Open on LeetCode

Problem

Given a lowercase string s and an integer k, return the maximum number of vowels (a, e, i, o, u) in any substring of length k.

Example 1

Input:       s = "abciiidef", k = 3
Output:      3
Explanation: 'iii' has 3 vowels.

Example 2

Input:       s = "aeiou", k = 2
Output:      2
Explanation: Every window has 2 vowels.

Example 3

Input:       s = "leetcode", k = 3
Output:      2
Explanation: 'lee', 'eet' and 'ode' have 2.

Constraints: 1 ≤ s.length ≤ 10⁵, 1 ≤ k ≤ s.length

Solution

class Solution {
public:
    bool isVowel(char c) {                           // ✏️ changed | helper: is c a vowel?
        return c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u';   // ✏️ changed | one of the 5 vowels
    }

    int maxVowels(string s, int k) {   // ✏️ changed
        int n = s.size();                            // ✏️ changed | length of the string
        int left = 0, right = 0;                     // window is s[left..right]
        int vowelCount = 0;                          // ✏️ changed | vowels in the current window
        int bestCount = 0;                           // ✏️ changed | most vowels seen in any window

        while (right < n) {                          // grow the window one character at a time
            if (isVowel(s[right])) vowelCount++;     // ✏️ changed | ADD: s[right] enters the window

                left++;                              // shrink from the left

                bestCount = max(bestCount, vowelCount);   // ✏️ changed | UPDATE: keep the biggest count
            }
            right++;                                 // move to the next character
        }
        return bestCount;                            // ✏️ changed | max vowels in a window
    }
};

Time & Space Complexity: Time O(n): har character ek baar aata hai, ek baar jaata hai. Space O(1).

8. LC 1151 — Minimum Swaps to Group All 1’s Together

Open on LeetCode · 🔒 Premium

Problem

Given a binary array data, return the minimum number of swaps (any two positions) needed to bring all the 1s together into one contiguous block, anywhere in the array.

Example 1

Input:       data = [1,0,1,0,1]
Output:      1
Explanation: 3 ones. The best window of size 3, [1,0,1], has one 0, so 1 swap.

Example 2

Input:       data = [0,0,0,1,0]
Output:      0
Explanation: Only one 1; already grouped.

Example 3

Input:       data = [1,0,1,0,1,0,0,1,1,0,1]
Output:      3
Explanation: 6 ones. The best window of size 6 has 3 zeros.

Constraints: 1 ≤ n ≤ 10⁵, data[i] is 0 or 1

Solution

class Solution {
public:
    int minSwaps(vector<int>& nums) {   // ✏️ changed
        int n = nums.size();                         // ✏️ changed | length of the array
        int k = 0;                                   // ✏️ changed | window size = total number of 1s
        for (int x : nums) if (x == 1) k++;          // ✏️ changed | count all 1s
        if (k == 0) return 0;                        // ✏️ changed | no 1s, nothing to group
        int left = 0, right = 0;                     // window is nums[left..right]
        int zeroCount = 0;                           // ✏️ changed | 0s inside the current window
        int bestCount = INT_MAX;                     // fewest 0s seen in any window

        while (right < n) {                          // grow the window one element at a time
            if (nums[right] == 0) zeroCount++;       // ✏️ changed | ADD: nums[right] enters the window

            while (right - left + 1 > k) {           // window became bigger than k
                if (nums[left] == 0) zeroCount--;    // ✏️ changed | REMOVE: nums[left] leaves the window
                left++;                              // shrink from the left
            }

            if (right - left + 1 == k) {             // window has exactly k elements
                bestCount = min(bestCount, zeroCount);   // ✏️ changed | UPDATE: each 0 here needs one swap
            }
            right++;                                 // move to the next element
        }
        return bestCount;                            // min swaps
    }
};

Time & Space Complexity: Time O(n): ek pass 1s ginne ke liye, ek pass window ke liye. Space O(1).

9. LC 1052 — Grumpy Bookstore Owner

Open on LeetCode

Problem

customers[i] people come in minute i. If grumpy[i] = 1 the owner is grumpy that minute and those customers are unhappy; otherwise they are happy. Once, the owner can stay calm for minutes consecutive minutes. Return the maximum number of happy customers.

Example 1

Input:       customers = [1,0,1,2,1,1,7,5], grumpy = [0,1,0,1,0,1,0,1], minutes = 3
Output:      16
Explanation: Already happy: 1+1+1+7 = 10. Staying calm in the last 3 minutes saves 1+5 = 6, total 16.

Example 2

Input:       customers = [1], grumpy = [0], minutes = 1
Output:      1

Constraints: 1 ≤ n ≤ 2·10⁴, 1 ≤ minutes ≤ n, 0 ≤ customers[i] ≤ 1000

Solution

class Solution {
public:
    int maxSatisfied(vector<int>& customers, vector<int>& grumpy, int k) {   // ✏️ changed
        int n = customers.size();                    // ✏️ changed | number of minutes
        int baseSatisfied = 0;                       // ✏️ changed | customers happy without the trick
        for (int i = 0; i < n; i++) {                // ✏️ changed | go over every minute
            if (grumpy[i] == 0) baseSatisfied += customers[i];   // ✏️ changed | owner not grumpy, already happy
        }
        int left = 0, right = 0;                     // window is minutes[left..right]
        int extraCount = 0;                          // ✏️ changed | grumpy-minute customers inside the window
        int bestExtra = 0;                           // ✏️ changed | most customers the trick can save

        while (right < n) {                          // grow the window one minute at a time
            if (grumpy[right] == 1) extraCount += customers[right];   // ✏️ changed | ADD: these become happy

            while (right - left + 1 > k) {           // window became bigger than k
                if (grumpy[left] == 1) extraCount -= customers[left];   // ✏️ changed | REMOVE: oldest minute leaves
                left++;                              // shrink from the left
            }

            if (right - left + 1 == k) {             // window has exactly k minutes
                bestExtra = max(bestExtra, extraCount);   // ✏️ changed | UPDATE: best window for the trick
            }
            right++;                                 // move to the next minute
        }
        return baseSatisfied + bestExtra;            // ✏️ changed | always happy + saved by the trick
    }
};

Time & Space Complexity: Time O(n): ek pass base ke liye, ek pass window ke liye. Space O(1).

10. LC 3652 — Best Time to Buy and Sell Stock using Strategy

Open on LeetCode

Problem

prices[i] is the price on day i and strategy[i] is −1 (buy), 0 (hold) or 1 (sell); profit = sum of strategy[i] × prices[i]. You may do at most one change: pick k consecutive days (k is even), set the first k/2 of them to hold and the last k/2 to sell. Return the maximum possible profit.

Example 1

Input:       prices = [4,2,8], strategy = [-1,0,1], k = 2
Output:      10
Explanation: Original profit −4 + 0 + 8 = 4. Changing days 0–1 to [hold, sell] gives 0 + 2 + 8 = 10.

Example 2

Input:       prices = [5,4,3], strategy = [1,1,0], k = 2
Output:      9
Explanation: Original profit 9 is already the best, so no change.

Constraints: 2 ≤ n ≤ 10⁵, 1 ≤ prices[i] ≤ 10⁵, strategy[i] ∈ {−1, 0, 1}, 2 ≤ k ≤ n, k even

Solution

class Solution {
public:
    long long maxProfit(vector<int>& prices, vector<int>& strategy, int k) {   // ✏️ changed
        int n = prices.size();                       // ✏️ changed | number of days
        long long baseProfit = 0;                    // ✏️ changed | profit with the original strategy (up to 10^10)
        for (int i = 0; i < n; i++) {                // go over every day
            baseProfit += (long long)strategy[i] * prices[i];   // ✏️ changed | -1 buy, 0 hold, 1 sell
        }
        int half = k / 2;                            // ✏️ changed | first half = hold, second half = sell
        int left = 0, right = 0;                     // window is days[left..right]
        int mid = 0;                                 // ✏️ changed | sell half is days[mid..right]
        long long windowProfit = 0;                  // ✏️ changed | original profit inside the window (we give it up)
        long long sellHalfPrices = 0;                // ✏️ changed | prices of the sell half
        long long bestGain = 0;                      // ✏️ changed | 0 means: do not modify anything

        while (right < n) {                          // grow the window one day at a time
            windowProfit += (long long)strategy[right] * prices[right];   // ✏️ changed | ADD: its original profit
            sellHalfPrices += prices[right];         // ✏️ changed | ADD: newest day is in the sell half

            while (right - mid + 1 > half) {         // ✏️ changed | sell half became bigger than k/2
                sellHalfPrices -= prices[mid];       // ✏️ changed | this day moves to the hold half
                mid++;                               // ✏️ changed | shrink the sell half
            }

            while (right - left + 1 > k) {           // window became bigger than k
                windowProfit -= (long long)strategy[left] * prices[left];   // ✏️ changed | REMOVE: oldest day leaves
                left++;                              // shrink from the left
            }

            if (right - left + 1 == k) {             // window has exactly k days
                bestGain = max(bestGain, sellHalfPrices - windowProfit);   // ✏️ changed | UPDATE: new profit - old profit
            }
            right++;                                 // move to the next day
        }
        return baseProfit + bestGain;                // ✏️ changed | original + best improvement
    }
};

Time & Space Complexity: Time O(n): right, left aur mid teeno total n baar hi aage badhte hain. Space O(1).

11. LC 3694 — Distinct Points Reachable After Substring Removal

Open on LeetCode

Problem

s has moves ‘U’, ‘D’, ‘L’, ‘R’ on a grid, starting at (0, 0). You must delete exactly one substring of length k, then do the remaining moves in order. Return how many different final points are possible.

Example 1

Input:       s = "LUL", k = 1
Output:      2
Explanation: Remaining 'UL', 'LL', 'LU' end at (−1,1), (−2,0), (−1,1): 2 different points.

Example 2

Input:       s = "UDLR", k = 4
Output:      1
Explanation: Everything is deleted; you stay at (0,0).

Example 3

Input:       s = "UU", k = 1
Output:      1
Explanation: Always ends at (0,1).

Constraints: 1 ≤ n ≤ 10⁵, 1 ≤ k ≤ n

Solution

class Solution {
public:
    int stepX(char c) {                              // ✏️ changed | helper: x change for a move
        if (c == 'R') return 1;                      // ✏️ changed | right: x + 1
        if (c == 'L') return -1;                     // ✏️ changed | left: x - 1
        return 0;                                    // ✏️ changed | up/down do not change x
    }
    int stepY(char c) {                              // ✏️ changed | helper: y change for a move
        if (c == 'U') return 1;                      // ✏️ changed | up: y + 1
        if (c == 'D') return -1;                     // ✏️ changed | down: y - 1
        return 0;                                    // ✏️ changed | left/right do not change y
    }

    int distinctPoints(string s, int k) {   // ✏️ changed
        int n = s.size();                            // ✏️ changed | number of moves
        int totalX = 0, totalY = 0;                  // ✏️ changed | end point if nothing is removed
        for (char c : s) {                           // ✏️ changed | walk all moves
            totalX += stepX(c);                      // ✏️ changed | add x change
            totalY += stepY(c);                      // ✏️ changed | add y change
        }
        int left = 0, right = 0;                     // window is s[left..right]
        int windowX = 0, windowY = 0;                // ✏️ changed | movement done by the current window
        set<pair<int, int>> finalPoints;             // ✏️ changed | distinct end points

        while (right < n) {                          // grow the window one move at a time
            windowX += stepX(s[right]);              // ✏️ changed | ADD: its x change
            windowY += stepY(s[right]);              // ✏️ changed | ADD: its y change

            while (right - left + 1 > k) {           // window became bigger than k
                windowX -= stepX(s[left]);           // ✏️ changed | REMOVE: oldest move leaves (x)
                windowY -= stepY(s[left]);           // ✏️ changed | REMOVE: oldest move leaves (y)
                left++;                              // shrink from the left
            }

            if (right - left + 1 == k) {             // window has exactly k moves
                finalPoints.insert({totalX - windowX, totalY - windowY});   // ✏️ changed | UPDATE: end point without this window
            }
            right++;                                 // move to the next move
        }
        return finalPoints.size();                   // ✏️ changed | number of distinct end points
    }
};

Time & Space Complexity: Time O(n log n): har window ka end point set mein daalna O(log n). Space O(n), set ke liye.

16. LC 2524 — Maximum Frequency Score of a Subarray

Open on LeetCode · 🔒 Premium

Problem

The frequency score of an array is the sum, over each distinct value v, of v raised to the power of its frequency, taken modulo 10⁹ + 7. Return the maximum frequency score of a subarray of size k. Maximize the value after taking the modulo, not the real value.

Example 1

Input:       nums = [1,1,1,2,1,2], k = 3
Output:      5
Explanation: [2,1,2] → 2² + 1¹ = 5.

Example 2

Input:       nums = [1,1,1,1,1,1], k = 4
Output:      1
Explanation: 1⁴ = 1.

Constraints: 1 ≤ k ≤ n ≤ 10⁵, 1 ≤ nums[i] ≤ 10⁶

Solution

class Solution {
public:
    const long long MOD = 1000000007;                // ✏️ changed | scores are taken modulo this

    long long power(long long base, long long exp) { // ✏️ changed | helper: base^exp % MOD (fast power)
        long long result = 1;                        // ✏️ changed | answer so far
        base %= MOD;                                 // ✏️ changed | keep base small
        while (exp > 0) {                            // ✏️ changed | binary exponentiation
            if (exp & 1) result = result * base % MOD;   // ✏️ changed | use this bit
            base = base * base % MOD;                // ✏️ changed | square the base
            exp >>= 1;                               // ✏️ changed | move to the next bit
        }
        return result;                               // ✏️ changed | base^exp % MOD
    }

    int maxFrequencyScore(vector<int>& nums, int k) {   // ✏️ changed
        int n = nums.size();                         // number of elements
        int left = 0, right = 0;                     // window is nums[left..right]
        unordered_map<int, int> freq;                // value -> count inside the window
        long long score = 0;                         // ✏️ changed | sum of value^freq over different values (mod)
        long long bestScore = 0;                     // ✏️ changed | best score seen (under the modulo)

        while (right < n) {                          // grow the window one element at a time
            int value = nums[right];                 // ✏️ changed | the value that enters
            if (freq[value] > 0) score = (score - power(value, freq[value]) + MOD) % MOD;   // ✏️ changed | ADD: drop its old term
            freq[value]++;                           // ✏️ changed | ADD: its count goes up
            score = (score + power(value, freq[value])) % MOD;   // ✏️ changed | ADD: add its new term

            while (right - left + 1 > k) {           // window became bigger than k
                int old = nums[left];                // ✏️ changed | the value that leaves
                score = (score - power(old, freq[old]) + MOD) % MOD;   // ✏️ changed | REMOVE: drop its old term
                freq[old]--;                         // ✏️ changed | REMOVE: its count goes down
                if (freq[old] > 0) score = (score + power(old, freq[old])) % MOD;   // ✏️ changed | REMOVE: add its new term
                left++;                              // shrink from the left
            }

            if (right - left + 1 == k) {             // window has exactly k elements
                bestScore = max(bestScore, score);   // ✏️ changed | UPDATE: keep the biggest score
            }
            right++;                                 // move to the next element
        }
        return bestScore;                            // ✏️ changed | max frequency score
    }
};

Time & Space Complexity: Time O(n log k): har ADD/REMOVE pe ek fast power, aur exponent ≤ k. Space O(k).

        for (char c : pattern) needFreq[c - 'a']++;  // count pattern letters
        int left = 0, right = 0;                     // window is text[left..right]
        vector<int> windowFreq(26, 0);               // letter counts of the current window
        vector<int> starts;                          // ✏️ changed | start index of every anagram

        while (right < n) {                          // grow the window one character at a time
            windowFreq[text[right] - 'a']++;         // ADD: count it

            while (right - left + 1 > k) {           // window became bigger than k
                windowFreq[text[left] - 'a']--;      // REMOVE: uncount it
                left++;                              // shrink from the left
            }

            if (right - left + 1 == k) {             // window has exactly k characters
                if (windowFreq == needFreq) starts.push_back(left);   // ✏️ changed | UPDATE: save where it starts
            }
            right++;                                 // move to the next character
        }
        return starts;                               // ✏️ changed | all anagram start indices
    }
};

Time & Space Complexity: Time O(26 × n). Space O(26) (output alag).
