1. LC 209 — Minimum Size Subarray Sum

Open on LeetCode

Problem

Given an array of positive integers nums and a positive integer target, return the minimal length of a subarray whose sum is greater than or equal to target. If there is no such subarray, return 0.

Example 1

Input:       target = 7, nums = [2,3,1,2,4,3]
Output:      2
Explanation: [4,3] sums to 7 and no single element reaches 7.

Example 2

Input:       target = 4, nums = [1,4,4]
Output:      1
Explanation: [4] alone reaches 4.

Example 3

Input:       target = 11, nums = [1,1,1,1,1,1,1,1]
Output:      0
Explanation: The whole array sums to only 8.

Constraints: 1 ≤ target ≤ 10⁹, 1 ≤ nums.length ≤ 10⁵, 1 ≤ nums[i] ≤ 10⁴

Solution

class Solution {
public:
    int minSubArrayLen(int target, vector<int>& nums) {
        int n = nums.size();                         // number of elements
        int left = 0, right = 0;                     // window is nums[left..right]
        int windowSum = 0;                           // sum of the current window (max 10^9, fits in int)
        int bestLen = INT_MAX;                       // shortest valid window seen so far

        while (right < n) {                          // grow the window one element at a time
            windowSum += nums[right];                // ADD: nums[right] enters the window

            while (windowSum >= target) {            // window is valid: try to make it shorter
                bestLen = min(bestLen, right - left + 1);   // UPDATE: keep the shortest valid window
                windowSum -= nums[left];             // REMOVE: nums[left] leaves the window
                left++;                              // shrink from the left
            }
            right++;                                 // move to the next element
        }
        return bestLen == INT_MAX ? 0 : bestLen;     // 0 if no window reached target
    }
};

Time & Space Complexity: Time O(n): right n baar aage badhta hai aur left bhi total n baar se zyada nahi, toh har element ek baar aata hai aur ek baar jaata hai. Space O(1).

2. LC 2875 — Minimum Size Subarray in Infinite Array

Open on LeetCode

Problem

You are given an array nums and an integer target. Imagine infinite_nums, made by repeating nums forever (for [1,2,3] it is [1,2,3,1,2,3,1,2,3,…]). Return the length of the shortest subarray of infinite_nums whose sum equals target, or −1 if there is none.

Example 1

Input:       nums = [1,2,3], target = 5
Output:      2
Explanation: infinite_nums = [1,2,3,1,2,3,...]; [2,3] at index 1–2 sums to 5.

Example 2

Input:       nums = [1,1,1,2,3], target = 4
Output:      2
Explanation: infinite_nums = [1,1,1,2,3,1,1,1,2,3,...]; [3,1] at index 4–5 sums to 4.

Example 3

Input:       nums = [2,4,6,8], target = 3
Output:      -1
Explanation: Every number is even, so an odd sum like 3 is impossible.

Constraints: 1 ≤ nums.length ≤ 10⁵, 1 ≤ nums[i] ≤ 10⁵, 1 ≤ target ≤ 10⁹

Solution

class Solution {
public:
    int minSizeSubarray(vector<int>& nums, int target) {   // ✏️ changed
        int n = nums.size();                         // length of one copy
        long long total = 0;                         // ✏️ changed | sum of one full copy (can reach 10^10)
        for (int x : nums) total += x;               // ✏️ changed | add up one copy
        long long fullCopies = target / total;       // ✏️ changed | whole copies we take for sure
        long long rest = target % total;             // ✏️ changed | the part a window still has to make
        if (rest == 0) return fullCopies * n;        // ✏️ changed | only full copies needed
        int left = 0, right = 0;                     // window is over nums + nums (2n elements)
        long long windowSum = 0;                     // ✏️ changed | sum of the current window
        int bestLen = INT_MAX;                       // shortest valid window seen so far

        while (right < 2 * n) {                      // ✏️ changed | two copies are enough for any wrap-around
            windowSum += nums[right % n];            // ✏️ changed | ADD: nums[right % n] enters the window

            while (windowSum >= rest) {              // ✏️ changed | window is valid: try to make it shorter
                if (windowSum == rest) bestLen = min(bestLen, right - left + 1);   // ✏️ changed | UPDATE: exact sum only
                windowSum -= nums[left % n];         // ✏️ changed | REMOVE: nums[left % n] leaves the window
                left++;                              // shrink from the left
            }
            right++;                                 // move to the next element
        }
        return bestLen == INT_MAX ? -1 : fullCopies * n + bestLen;   // ✏️ changed | full copies + the window
    }
};

Time & Space Complexity: Time O(n): window sirf 2n elements pe chalta hai, right aur left dono total 2n baar. Space O(1).

3. LC 3795 — Minimum Subarray Length With Distinct Sum At Least K

Open on LeetCode

Problem

You are given an integer array nums and an integer k. For a subarray, add up its distinct values, counting each value only once. Return the minimum length of a subarray whose distinct sum is at least k, or −1 if no such subarray exists.

Example 1

Input:       nums = [2,2,3,1], k = 4
Output:      2
Explanation: [2,3] has distinct values {2, 3}; 2 + 3 = 5 ≥ 4.

Example 2

Input:       nums = [3,2,3,4], k = 5
Output:      2
Explanation: [3,2]: 3 + 2 = 5 ≥ 5.

Example 3

Input:       nums = [5,5,4], k = 5
Output:      1
Explanation: [5] alone reaches 5.

Constraints: 1 ≤ nums.length ≤ 10⁵, 1 ≤ nums[i] ≤ 10⁵, 1 ≤ k ≤ 10⁹

Solution

class Solution {
public:
    int minLength(vector<int>& nums, int k) {   // ✏️ changed
        int n = nums.size();                         // number of elements
        int left = 0, right = 0;                     // window is nums[left..right]
        unordered_map<int, int> freq;                // ✏️ changed | value -> count inside the window
        long long distinctSum = 0;                   // ✏️ changed | sum of different values in the window (can pass int)
        int bestLen = INT_MAX;                       // shortest valid window seen so far

        while (right < n) {                          // ✏️ changed | grow the window one element at a time
            if (freq[nums[right]] == 0) distinctSum += nums[right];   // ✏️ changed | ADD: a value we did not have yet
            freq[nums[right]]++;                     // ✏️ changed | ADD: count it

            while (distinctSum >= k) {               // ✏️ changed | window is valid: try to make it shorter
                bestLen = min(bestLen, right - left + 1);   // ✏️ changed | UPDATE: keep the shortest valid window
                freq[nums[left]]--;                  // ✏️ changed | REMOVE: uncount it
                if (freq[nums[left]] == 0) distinctSum -= nums[left];   // ✏️ changed | REMOVE: that value is gone now
                left++;                              // shrink from the left
            }
            right++;                                 // move to the next element
        }
        return bestLen == INT_MAX ? -1 : bestLen;    // ✏️ changed | -1 if no window reached k
    }
};

Time & Space Complexity: Time O(n) average. Space O(n): map se key kabhi hatti nahi.

4. LC 2260 — Minimum Consecutive Cards to Pick Up

Open on LeetCode

Problem

You are given an integer array cards where cards[i] is the value of the i-th card. Two cards match if they have the same value. Return the minimum number of consecutive cards you have to pick up to get a pair of matching cards. If it is impossible, return −1.

Example 1

Input:       cards = [3,4,2,3,4,7]
Output:      4
Explanation: Pick [3,4,2,3] (the two 3s) or [4,2,3,4] (the two 4s). Nothing shorter has a pair.

Example 2

Input:       cards = [1,0,5,3]
Output:      -1
Explanation: All values are different, so no pair exists.

Constraints: 1 ≤ cards.length ≤ 10⁵, 0 ≤ cards[i] ≤ 10⁶

Solution

class Solution {
public:
    int minimumCardPickup(vector<int>& nums) {   // ✏️ changed
        int n = nums.size();                         // number of cards
        int left = 0, right = 0;                     // window is nums[left..right]
        unordered_map<int, int> freq;                // value -> count inside the window
        int bestLen = INT_MAX;                       // shortest valid window seen so far

        while (right < n) {                          // grow the window one card at a time
            freq[nums[right]]++;                     // ADD: nums[right] enters the window

            while (freq[nums[right]] > 1) {          // ✏️ changed | window is valid: it has a matching pair
                bestLen = min(bestLen, right - left + 1);   // UPDATE: keep the shortest valid window
                freq[nums[left]]--;                  // REMOVE: nums[left] leaves the window
                left++;                              // shrink from the left
            }
            right++;                                 // move to the next card
        }
        return bestLen == INT_MAX ? -1 : bestLen;    // -1 if no pair exists
    }
};

Time & Space Complexity: Time O(n) average. Space O(n): map se key kabhi hatti nahi.

5. LC 2904 — Shortest and Lexicographically Smallest Beautiful String

Open on LeetCode

Problem

You are given a binary string s and a positive integer k. A substring is beautiful if it has exactly k ones. Let len be the length of the shortest beautiful substring. Return the lexicographically smallest beautiful substring of length len, or an empty string if s has no beautiful substring. (Lexicographically smaller: at the first position where two strings differ, the one with the smaller character is smaller.)

Example 1

Input:       s = "100011001", k = 3
Output:      "11001"
Explanation: Many substrings have exactly 3 ones; the shortest have length 5, and the smallest of those is '11001'.

Example 2

Input:       s = "1011", k = 2
Output:      "11"
Explanation: '11' is the only length-2 substring with two ones.

Example 3

Input:       s = "000", k = 1
Output:      ""
Explanation: There is no '1' at all.

Constraints: 1 ≤ s.length ≤ 100, 1 ≤ k ≤ s.length

Solution

class Solution {
public:
    string shortestBeautifulSubstring(string s, int k) {   // ✏️ changed
        int n = s.size();                            // ✏️ changed | length of the string
        int left = 0, right = 0;                     // window is s[left..right]
        int oneCount = 0;                            // ✏️ changed | '1's inside the window
        int bestLen = INT_MAX;                       // shortest valid window seen so far
        string best = "";                            // ✏️ changed | the answer substring so far

        while (right < n) {                          // grow the window one character at a time
            if (s[right] == '1') oneCount++;         // ✏️ changed | ADD: s[right] enters the window

            while (oneCount == k) {                  // ✏️ changed | window is valid: exactly k ones, try to make it shorter
                string window = s.substr(left, right - left + 1);   // ✏️ changed | the current substring
                if (right - left + 1 < bestLen || (right - left + 1 == bestLen && window < best)) {   // ✏️ changed | UPDATE: shorter, or same length but smaller
                    bestLen = right - left + 1;      // ✏️ changed | new best length
                    best = window;                   // ✏️ changed | new best substring
                }
                if (s[left] == '1') oneCount--;      // ✏️ changed | REMOVE: s[left] leaves the window
                left++;                              // shrink from the left
            }
            right++;                                 // move to the next character
        }
        return best;                                 // ✏️ changed | "" if no window has k ones
    }
};

Time & Space Complexity: Time O(n²) worst case: har UPDATE pe substr aur string compare O(n), aur n ≤ 100. Space O(n).

6. LC 1234 — Replace the Substring for Balanced String

Open on LeetCode

Problem

You are given a string s of length n containing only ‘Q’, ‘W’, ‘E’ and ‘R’ (n is a multiple of 4). The string is balanced if each of the four characters appears exactly n/4 times. Return the minimum length of a substring that you can replace with any other string of the same length to make s balanced. If s is already balanced, return 0.

Example 1

Input:       s = "QWER"
Output:      0
Explanation: Already balanced.

Example 2

Input:       s = "QQWE"
Output:      1
Explanation: Replace one 'Q' with 'R': 'RQWE'.

Example 3

Input:       s = "QQQW"
Output:      2
Explanation: Replace the first 'QQ' with 'ER': 'ERQW'.

Constraints: n == s.length, 4 ≤ n ≤ 10⁵, n is a multiple of 4, s contains only ‘Q’, ‘W’, ‘E’ and ‘R’

Solution

class Solution {
public:
    int balancedString(string s) {   // ✏️ changed
        int n = s.size();                            // length of the string
        int need = n / 4;                            // ✏️ changed | every letter must appear exactly n/4 times
        vector<int> outside(128, 0);                 // ✏️ changed | letter -> count OUTSIDE the window
        for (char c : s) outside[c]++;               // ✏️ changed | at the start everything is outside
        if (outside['Q'] == need && outside['W'] == need && outside['E'] == need && outside['R'] == need) return 0;   // ✏️ changed | already balanced
        int left = 0, right = 0;                     // window is s[left..right] (the part we replace)
        int bestLen = INT_MAX;                       // shortest valid window seen so far

        while (right < n) {                          // grow the window one character at a time
            outside[s[right]]--;                     // ✏️ changed | ADD: s[right] moves into the window

            while (outside['Q'] <= need && outside['W'] <= need && outside['E'] <= need && outside['R'] <= need) {   // ✏️ changed | window is valid: rewriting it can fix the rest
                bestLen = min(bestLen, right - left + 1);   // ✏️ changed | UPDATE: keep the shortest valid window
                outside[s[left]]++;                  // ✏️ changed | REMOVE: s[left] goes back outside
                left++;                              // shrink from the left
            }
            right++;                                 // move to the next character
        }
        return bestLen;                              // ✏️ changed | shortest substring to replace
    }
};

Time & Space Complexity: Time O(n). Space O(1) (128 size ka array).

7. LC 76 — Minimum Window Substring

Open on LeetCode

Problem

Given strings s and t, return the shortest substring of s that contains every character of t, including duplicates. If there is none, return the empty string. The answer is guaranteed to be unique.

Example 1

Input:       s = "ADOBECODEBANC", t = "ABC"
Output:      "BANC"
Explanation: 'BANC' has A, B and C, and no shorter substring does.

Example 2

Input:       s = "a", t = "a"
Output:      "a"
Explanation: The whole string.

Example 3

Input:       s = "a", t = "aa"
Output:      ""
Explanation: t needs two 'a', but s has only one.

Constraints: m == s.length, n == t.length, 1 ≤ m, n ≤ 10⁵, s and t are uppercase and lowercase English letters

Solution

class Solution {
public:
    string minWindow(string s, string t) {
        if(s.size() < t.size())return ""; //include this two base cases
        if(s == t) return s;
        unordered_map<char, int>mp;
        for(int i = 0; i < t.size(); i++){
            mp[t[i]]++;
        }
        int r = 0, l = 0, cnt= 0, minlen = INT_MAX, ind = -1;
        while(r < s.size()){
            if(mp[s[r]] > 0){
                cnt++;
            }
            mp[s[r]]--;
            while(cnt == t.size() && l <= r){
                if(r-l+1 < minlen){
                    minlen = r-l+1;
                    ind = l;
                }
                mp[s[l]]++;
                if(mp[s[l]] > 0) {
                    cnt--;
                }
                l++;
            }
            r++;
        }
        if(ind == -1)return "";
        string str = s.substr(ind, minlen);
        return str;
    }
};

Time & Space Complexity: Time O(m + n): r aur l dono total m baar aage badhte hain, aur t ko ek baar ginna. Space O(1): map mein max 52 letters (A–Z, a–z).

8. LC 3297 — Count Substrings That Can Be Rearranged to Contain a String I

Open on LeetCode

Problem

You are given two strings word1 and word2. A string x is valid if it can be rearranged so that word2 is a prefix of it, which means x contains every letter of word2 at least as many times. Return the number of valid substrings of word1.

Example 1

Input:       word1 = "bcca", word2 = "abc"
Output:      1
Explanation: Only 'bcca' works: it rearranges to 'abcc', which starts with 'abc'.

Example 2

Input:       word1 = "abcabc", word2 = "abc"
Output:      10
Explanation: Every substring of length 3 or more has a, b and c: 4 + 3 + 2 + 1 = 10.

Example 3

Input:       word1 = "abcabc", word2 = "aaabc"
Output:      0
Explanation: 'aaabc' needs three 'a', but word1 has only two.

Constraints: 1 ≤ word1.length ≤ 10⁵, 1 ≤ word2.length ≤ 10⁴, word1 and word2 are lowercase letters

Solution

class Solution {
public:
    long long validSubstringCount(string s, string t) {   // ✏️ changed
        if(s.size() < t.size())return 0; // ✏️ changed | shorter s cannot contain t
        unordered_map<char, int>mp;
        for(int i = 0; i < t.size(); i++){
            mp[t[i]]++;
        }
        int r = 0, l = 0, cnt= 0;   // ✏️ changed
        long long ans = 0; // ✏️ changed | number of valid substrings (can pass int)
        while(r < s.size()){
            if(mp[s[r]] > 0){
                cnt++;
            }
            mp[s[r]]--;
            while(cnt == t.size() && l <= r){
                mp[s[l]]++;
                if(mp[s[l]] > 0) {
                    cnt--;
                }
                l++;
            }
            ans += l; // ✏️ changed | starts 0..l-1 all give a valid substring ending at r
            r++;
        }
        return ans;   // ✏️ changed
    }
};

Time & Space Complexity: Time O(m + n): r aur l dono total m baar aage badhte hain. Space O(1): map mein max 26 letters. Answer m²/2 tak ja sakta hai, isliye long long.

9. LC 3298 — Count Substrings That Can Be Rearranged to Contain a String II
